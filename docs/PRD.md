# 奶豆 Windows 桌面美化主题
## 产品需求文档（PRD）

**项目代号：** MilkBean Desktop Theme  
**产品版本：** MVP 1.0  
**文档版本：** v1.0  
**目标平台：** Windows 10 / Windows 11 x64  
**产品类型：** 可下载、可安装、可恢复的数字主题商品  
**核心角色：** 奶豆原创 3D 卡通形象  

---

## 1. 产品概述

### 1.1 产品定位

为 Windows 用户提供一套以「奶豆」为主题的桌面美化资源包。用户无需自行编辑配置文件或手动修改大量系统设置，即可快速获得统一、精致且具有实用功能的桌面体验。

本产品不是单纯的壁纸合集，也不是需要用户自行折腾的 Rainmeter 皮肤集合，而是一个具备安装、应用、管理和恢复能力的桌面主题商品。

### 1.2 产品目标

1. 降低桌面美化的使用门槛，让普通用户也能轻松完成设置。
2. 保留奶豆原有的 3D 形象特征，不随意改变角色外观。
3. 提供真实可用的时钟、日历、便签等桌面组件。
4. 支持快速应用主题，并尽可能恢复用户原有桌面状态。
5. 形成可复制的商品生产流程，后续可以发布不同场景、颜色和节日主题。

### 1.3 产品价值

- **对用户：** 花少量费用即可获得完整、统一、方便安装的桌面美化体验。
- **对创作者：** 通过数字资源包销售获得收入，后续可以持续发布主题系列。
- **对产品本身：** 建立统一的资源规格、主题配置格式和安装机制，降低后续主题制作成本。

## 2. 目标用户

### 2.1 核心用户

- 喜欢可爱、治愈、简洁桌面的 Windows 用户。
- 喜欢更换壁纸、桌面小组件和文件夹图标的用户。
- 不熟悉 Rainmeter 配置，但希望一键完成桌面美化的用户。
- 喜欢奶豆形象、愿意为精致数字资源付费的用户。

### 2.2 用户痛点

| 用户痛点 | 产品解决方式 |
| --- | --- |
| 壁纸、组件和图标需要分别下载 | 提供完整主题包 |
| 不会安装和配置 Rainmeter | 提供引导式主题安装器 |
| 桌面组件只有装饰，没有实际功能 | 提供真实时钟、日历、便签 |
| 图标修改麻烦，容易忘记原样式 | 提供备份与恢复机制 |
| 不喜欢最终效果，却不知道怎么还原 | 提供一键恢复功能 |
| 不同显示器的布局不一致 | 支持分辨率适配与组件位置调整 |

## 4. 产品形态与交付方式

产品由两部分组成：

### 4.1 用户下载的商品包

用户购买后获得一个 ZIP 或安装程序下载包。

建议目录结构：

```
MilkBean-Desktop-Theme-01/
├── ApplyTheme.exe
├── RestoreTheme.exe
├── Uninstall.exe
├── Theme/
│   ├── theme.json
│   ├── Wallpaper/
│   ├── Rainmeter/Skins/MilkBean/
│   ├── Icons/
│   └── Assets/
├── Docs/
│   ├── README.pdf
│   └── Troubleshooting.pdf
└── LICENSE.txt
```

### 4.2 本地安装后的目录

建议使用当前用户目录，尽量不需要管理员权限：

```
%LOCALAPPDATA%\MilkBean\
├── App\
├── Themes\Desktop-01\
├── Config\
├── Backups\
└── Logs\
```

不允许安装器在用户不知情的情况下覆盖原始壁纸、清除其他桌面美化软件配置或删除用户文件。

## 5. 核心用户流程

### 5.1 首次安装
1. 用户下载主题包并运行 ApplyTheme.exe
2. 展示预览、功能介绍与安装说明
3. 检测 Windows 版本、架构、显示缩放和 Rainmeter 状态
4. 如需安装 Rainmeter，明确说明并征得同意
5. 检查主题文件完整性并备份当前设置
6. 安装组件、设置壁纸、时钟、日历和便签
7. 可选应用示例文件夹图标
8. 展示成功页（查看效果 / 恢复原状 / 完成）

### 5.2 再次应用主题
- 检测已安装状态与当前主题
- 用户确认后应用，保留便签与个性化设置

### 5.3 恢复原状
- 展示将恢复的项目并确认
- 关闭本产品组件，恢复有备份的原始设置
- 无法自动恢复的项目明确提示手动处理

### 5.4 卸载产品
- 恢复原状与卸载是两个独立操作
- 卸载前允许先恢复，并询问是否保留便签、备份与配置

## 6. 功能详细需求

### 6.1 主题安装器
欢迎页 → 环境检查页 → 安装选项页 → 完成页。所有可能影响用户现有设置的选项必须明确展示。

### 6.2 壁纸模块
静态壁纸，适配 16:9 常见分辨率（1920×1080 / 2560×1440 / 3840×2160），多显示器尽量保留各屏设置，设置前备份。

### 6.3 时钟模块
实时系统时间，支持 12/24 小时制，可拖动与保存位置，奶豆配色，低干扰。

### 6.4 日历模块
当前月份、切换上下月、突出当天，与系统区域设置一致，不联网。

### 6.5 便签模块
可创建/编辑/保存，多条便签，位置与尺寸可调，应用主题时保留内容。优先使用独立轻量窗口保证真实编辑体验。

### 6.6 文件夹图标模块
用户主动选择文件夹后应用奶豆风格 ICO，修改前备份，恢复时仅处理本产品修改过的文件夹。

### 6.7 主题管理
每个主题独立 theme.json，切换主题时不重置便签、用户位置与备份数据。

## 7. 视觉设计规范

### 7.1 品牌方向
以用户提供的奶豆形象为唯一角色视觉基准：黄色圆润身体、大眼睛、小圆嘴、3D 玩具质感、柔和阴影、呆萌表情。禁止改为扁平或其它不一致风格。

### 7.2 UI 风格
浅色背景，米白/奶油黄/暖灰，简洁卡片，少量轻动效，避免大面积紫色与复杂渐变。

### 7.3 桌面组件风格
轻量、安静、低干扰。默认：时钟右上，日历其下，便签右侧，壁纸中奶豆为视觉焦点且不遮挡常用图标。

## 8. 非功能需求

### 8.1 性能
安装器快速启动，组件无高频无意义刷新，静态主题无后台网络，不明显影响办公，无无关常驻进程。

### 8.2 安全与隐私
不上传壁纸/便签/桌面信息，不收集无关数据，不要求账号密码，不执行未说明的系统修改，优先普通用户权限。

### 8.3 兼容性
Windows 11/10 x64，常见 16:9 分辨率，100%–200% 缩放，单/双显示器，有无 Rainmeter 两种情况。
