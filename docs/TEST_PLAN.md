# 奶豆桌面主题 - 测试计划

**版本：** MVP 1.0  

---

## 1. 功能测试

- [ ] 首次应用主题
- [ ] 重复应用同一主题
- [ ] 设置与恢复壁纸
- [ ] 启用/关闭时钟与日历
- [ ] 创建、编辑、保存和重启恢复便签
- [ ] 设置与恢复文件夹图标
- [ ] 卸载主题
- [ ] 保留用户便签内容
- [ ] 恢复原有桌面状态

## 2. 兼容性测试

- [ ] Windows 11 / 10 x64
- [ ] 1920×1080 / 2560×1440 / 3840×2160
- [ ] 100% / 125% / 150% / 200% 缩放
- [ ] 单显示器 / 双显示器
- [ ] Rainmeter 已安装 / 未安装
- [ ] 普通用户权限

## 3. 异常测试

- [ ] 主题资源被删除
- [ ] 便签 JSON 损坏
- [ ] 应用过程中强制关闭或取消
- [ ] Rainmeter 启动失败
- [ ] 文件夹在恢复前被移动/删除
- [ ] 用户手动修改图标后执行恢复
- [ ] 磁盘空间不足

## 4. 验收标准（发布门槛）

1. 普通用户能根据安装器提示完成安装
2. 时钟、日历、便签具备实际功能
3. 便签关闭与重启后仍保留
4. 用户可主动选择文件夹并应用图标
5. 备份可读取，恢复可执行
6. 不覆盖用户已有 Rainmeter 皮肤
7. 安装失败提供可理解错误信息
8. 卸载不删除用户自己的文件
9. 在声明支持的系统与显示配置下完成测试
10. 发布包资源有明确使用与分发授权
